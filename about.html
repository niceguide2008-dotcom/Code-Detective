ABOUT CODE DETECTIVE

Learn like a detective.

Code Detective turns programming practice into an interactive investigation built around cases, evidence, experimentation, and genuine problem solving.

Last updated: August 16, 2026

What is Code Detective?

Code Detective is an interactive programming-learning experience built around investigation, experimentation, and problem solving. Programming practice is presented as cases to investigate rather than as a simple list of exercises.

🔎 Investigate

Examine code, clues, programming concepts, and the evidence presented in each challenge.

🧠 Understand

Focus on why a solution works instead of only memorising a final answer.

🧩 Practice

Work through interactive cases and use the Playground to assemble program components.

🏆 Progress

Build consistency through challenge completion, XP, mastery, and achievements.

The Playground

The Playground provides an interactive whiteboard for assembling Java program components, rearranging them, and checking the resulting program.

Our goal

Make programming practice more engaging, visual, and approachable while keeping genuine understanding at the centre of the experience.
